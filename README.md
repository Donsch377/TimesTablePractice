# Math Practice

A GitHub Pages practice app with times tables, linear expressions, multiplying and factoring, and dice equation puzzles.

## How It Works

- Choose a game from the first screen.
- Times Tables uses typed answers and fills the 1-12 table over time.
- Linear Expressions uses clear add, subtract, distribute, combine-like-terms, and recognition questions.
- Linear runs begin with easier questions and never repeat a question during the same run.
- Linear runs have a 30-second timer per question and a paused checkpoint every 10 correct answers.
- After the first checkpoint, linear-expression runs mix in written answers with a math keypad and 45-second timer.
- Multiplying & Factoring Linear Expressions practices distribution, monomial and binomial multiplication, and greatest-common-factor factoring.
- Completing the times-table board unlocks unlimited review while keeping all 144 cells filled.
- The site header tracks total correct answers across every game.
- What Makes _ gives five dice, a fixed bottom operation, and lets the player change only the two top symbols.
- Top expressions vary between parentheses layouts and normal order of operations.
- Every What Makes _ puzzle is checked for at least one exact solution before it is shown.
- Records and times-table mastery save on the device.
- A versioned copy/paste save code moves all game progress between devices and can support future games.
