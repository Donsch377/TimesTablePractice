# All Math Practice

A standalone GitHub Pages-ready practice game with:

- A first-screen game picker
- Linear-expression and times-table modes
- A 30-second timer for each question
- Paused checkpoints every 10 correct answers
- Per-game high scores and lifetime totals
- Versioned, copy/paste portable save codes

## Publish

Upload `index.html`, `styles.css`, and `app.js` to the root of a GitHub Pages repository. No build step is required.

For an existing site, these files can replace the current static page. If the existing site has a custom domain or other repository files, keep those files alongside these.
